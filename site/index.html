01 / 适配成果

为这款旧头显做了什么

从原生显示、视频交接到网站控件，围绕 Pico G2 的实际使用路径做适配。项目独立于 Wolvic 和 PICO 官方。

01

原生 PicoVR 与 WebXR

在 Wolvic 1.6.2 上恢复 G2 的 legacy PicoVR 后端，接入 GeckoView 128。保留 3DoF 头部追踪和手柄，已有普通网页、视频纹理及沉浸 WebXR 实机记录。

02

视频裁切与投影白屏

调整视频 Surface 尺寸更新和等待顺序，修复进入全屏后的持续裁切、投影切换白屏。提供原生 2D、180°、360° 和立体投影；特殊投影模型另有边界。

03

Hamezo 网页到原生交接

通用视频工具按媒体与渲染器归属交接，避免把整个网页放大成视频。Hamezo 的 Video.js VR 路径已有历史实机验收；原生接管后，网站 VR 按钮可能需要刷新恢复。

04

当前页 Quest UA 回退

部分网站非桌面模式不提供可用沉浸入口时，可对当前页使用 Quest/Oculus UA 并重新加载。离开后恢复原 UA；Pornhub / YouPorn 有历史实机记录，不承诺所有网站通用。

05

沉浸控件与悬停修复

共享 MGP SVG / CanvasTexture 兼容层处理黑色图标，补足 YouPorn 的 VR 激活判据；共用原生选择控件修复单行悬停闪烁。这些修复已有用户验收记录。

06

同视频真实多编码选择

按播放器和协议发现来源，至少两种确认可播放、可切换的编码族才显示菜单。Eporner H.264 / AV1 有自然网页双向证据；清晰度差异不算编码，失败恢复及其他路线限制均明确列出。

验证到了哪里

当前版保留历史实机成果，编码部分区分最终功能基线、历史自然网页与受控测试。新名称 APK 的功能资源已核对一致，但未单独重做头显安装验收；播放器适配器存在不等于所有网站都可切换。

04 / 安装

安装到 Pico G2

使用头显系统安装器，或从电脑通过 ADB 安装。下载后先核对 SHA256。

  1. 下载并核对 APK

    在头显浏览器下载，或从电脑传到头显的 Download 目录。

  2. 打开系统安装器

    按系统提示允许安装来源，也可使用 ADB 命令从电脑安装。

  3. 启动并测试普通网页

    在应用列表打开 Wolvic Pico G2。先确认普通网页和视频，再尝试网站沉浸入口。

adb devices
adb install -r .\Wolvic-1.6.2-picog2-20261113-arm64-signed.apk

这些命令安装新版，覆盖同包名测试候选。0052 包名不同，可保留并存；卸载任一应用会删除其本地数据。

下载前常见问题

这是 Pico G2 的 Firefox Reality 替代浏览器吗？

可以作为一个社区替代方案。它使用 Wolvic 1.6.2 与 GeckoView 128，为旧 Pico G2 提供较新的网页引擎，但不保证每个现代网站或流媒体服务兼容。

Pico 4、Neo、G3 或 Quest 能装吗？

这个移植针对 Pico G2 / G2 4K 系列。实际测试设备为 Android 8.1 的 G2，只有 arm64 构建。其他设备未验证，新头显应优先使用官方适配。

如何选择网页 VR 和原生视频投影？

先在普通网页启动视频。网站 VR 入口使用网页自己的沉浸播放器；浏览器扩展里的“VR 视频工具”用于原生投影或当前页 UA。网页全屏、网站 VR、原生投影分别处理，扩展在普通网页界面操作。原生接管部分渲染器后，网站 VR 按钮可能需要刷新恢复。

为什么有时没有媒体来源菜单？

来源选择要求同一视频至少两种真实、可播放编码得到确认。单编码、只有分辨率差异、身份不明或设备不支持时隐藏。旧版 0052 没有完整编码工具。

能保证 H.264 或 AV1 播放更流畅吗？

不能。网站、网络、分辨率、码率和设备解码能力都会影响体验。当前记录证明部分路径可以切换，不构成同规格流畅度对比。

遇到黑屏或视频无法播放怎么办？

先区分网络与解码问题，再测试普通视频。历史媒体资源异常曾通过完整重启头显恢复；这不是应用已永久修复资源问题的保证。

这是 Wolvic 或 PICO 官方产品吗？

不是。这是社区旧设备移植，采用 legacy PicoVR，而非当前 picoxr OpenXR 后端。源码沿用 MPL-2.0，第三方组件保留各自许可。
